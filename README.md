# পাঁচ মিশালি — ওয়েবসাইট ডেমো

GitHub Pages-এ চালু করার নিয়ম:
1. ZIP extract করুন। GitHub-এ একটি Public repository তৈরি করুন।
2. index.html, style.css, app.js, assets ফোল্ডার ও .nojekyll ফাইল root-এ আপলোড করুন। ZIP ফাইল আপলোড করবেন না।
3. Settings > Pages > Deploy from a branch > main > /(root) > Save।
4. ডেপ্লয় হলে Pages-এ পাওয়া লিংক খুলুন।

কোনো build বা package install লাগবে না। index.html খুলেও দেখা যাবে। ফন্ট লোড করতে ইন্টারনেট লাগে; না থাকলে ডিভাইসের ফন্ট ব্যবহৃত হবে।
